# PDF Studio v2

PDF・JPEG・PNGの結合・整理と、注釈・A4比率トリミングができる静的Webアプリです。ファイルはサーバーへ送信しません。

## 起動

```bash
npm install
npm run dev
```

## 本番ビルド

```bash
npm run build
```

`dist/` をCloudflare Pagesなどへ配置してください。

## 実装済み

- PDF・JPEG・PNG追加
- PDFページのサムネイル表示
- ドラッグ＆ドロップ並べ替え
- 複数選択、削除、90度回転
- 元に戻す／やり直す
- 白紙・区切り表紙の追加
- ページ番号の任意追加
- PDF書き出し
- 結合・整理／加工・編集の入口分離
- 縦一列のページ表示と移動先ガイド
- ペン、蛍光マーカー、四角、矢印、文字の重ね書き
- A4縦・横と同じ比率で切り取り、A4全面へ拡大出力
- 破損・未対応ファイルのエラー表示

## 注意

- パスワード付きPDFには対応していません。
- 元PDF内の既存文字そのものは編集せず、上から注釈を重ねる方式です。
