# PDF Studio

PDF・JPEG・PNGをブラウザ内で並べ替え、削除、回転、結合できる静的Webアプリです。ファイルはサーバーへ送信しません。

## 起動

```bash
npm install
npm run dev
```

## 本番ビルド

```bash
npm run build
```

`dist/` をCloudflare Pagesなどへ配置してください。

## 実装済み

- PDF・JPEG・PNG追加
- PDFページのサムネイル表示
- ドラッグ＆ドロップ並べ替え
- 複数選択、削除、90度回転
- 元に戻す／やり直す
- 白紙・区切り表紙の追加
- ページ番号の任意追加
- PDF書き出し
- 破損・未対応ファイルのエラー表示

## 注意

- パスワード付きPDFには対応していません。
- A4統一は縦横を維持し、余白内へ縮小して配置します。元ページは切り抜きません。
